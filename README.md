# Mr Handy

Маленькая утилита для macOS на Swift и AppKit. Наведи курсор на чёлку MacBook и нажми «Перезапустить звук»: macOS запросит права администратора, перезапустит звуковую службу и на несколько секунд прервёт звук. Пароль обрабатывает macOS; приложение его не хранит.

Для сборки нужны Apple Silicon, macOS 14 или новее и инструменты Xcode. Запусти `zsh build.sh`, затем открой `build/Mr Handy.app`. Панель также доступна через значок динамика в строке меню; там же можно выйти из приложения. На экране без чёлки панель открывается у середины верхнего края.
